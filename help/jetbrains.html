Clairn

Clairn for JetBrains IDEs

The Clairn plugin sends editor activity you have switched on to the Clairn agent on your own computer, and saves checkpoints you choose. Its commands are under Tools → Clairn.

Who it is for

IntelliJ IDEA, Android Studio, PyCharm, WebStorm and other IntelliJ-based IDEs on platform build 253 (2025.3) or newer, with Java 21. Check the build under Help → About. The plugin is installed from a ZIP file (Settings → Plugins → gear menu → Install Plugin from Disk). There is no Marketplace listing.

Pair and link a project

  1. Start the Clairn agent on your computer and get its token. Keep the token private.
  2. In Clairn open the project's editor connection controls and copy its project ID.
  3. In the IDE choose Tools → Clairn → Pair Agent and Link Project. Keep the default address http://127.0.0.1:43123, paste the project ID and the token, and save.
  4. Choose Test Agent Connection. This checks the connection only. It does not start capture.
  5. Choose Enable Activity Capture and read the confirmation. Capture is off by default for each project.

The token is kept in the IDE's Password Safe, never in plugin settings or logs. Only local loopback addresses are accepted, and repository files cannot switch capture on.

What is recorded

With capture on, the plugin records the project ID, language, timestamps, active seconds, the active file as a path relative to the project (or a salted code, or nothing, as you choose) and the current Git branch. It stops counting after 120 seconds without activity. It never sends source code, absolute paths, terminal text or commands. Leave Resume Note sends only the note you type. Save Workspace Checkpoint asks first and shares up to 30 open file names with cursor positions, plus your note and next action.

Restore a checkpoint

In Clairn copy the checkpoint for JetBrains. In the matching IDE project choose Tools → Clairn → Restore Checkpoint and paste it. The project must be trusted and its Clairn ID must match. Restoring opens the files at their saved positions and leaves your unsaved editors alone. It never runs commands, switches branches or restores file contents.

Pause, forget and queued data

  • Pause Activity Capture stops capture and sending for the project.
  • Delete Pending Activity empties the project's local queue. It does not delete events the agent already accepted.
  • Forget Agent Pairing Token pauses the project, clears its queue and removes the saved token.
  • The queue holds at most 100 events. The plugin never sends anything to GitHub, Supabase or any other online service.
