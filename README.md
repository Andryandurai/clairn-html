# Clairn

Landing page for **Clairn**: pick up exactly where you left off. Local-first, Windows app, optional Chrome extension.

Live page: https://andryandurai.github.io/clairn-html/

What is in this repository:

- `index.html`, also saved as `clairn-app.html`: the page.
- `help/`: three short setup guides the app links to (device sync, Linear/Jira/Google Calendar, JetBrains).
- `404.html`: the page GitHub Pages shows for an address that does not exist.
- `favicon.png`, `apple-touch-icon.png`, `og-image.png`: the tab icon, the iPhone home-screen icon and the picture shown when a link is shared.

The share picture and the icons use the address `https://andryandurai.github.io/clairn-html/`. If the site moves to its own domain, update `og:url`, `og:image`, `twitter:image` and the canonical link in each page.
